Use this glossary when a term in the guide is unfamiliar. The same map levels and system terms apply across all four roles, while each persona chapter explains the readings and actions relevant to that team.

## Glossary

| Term | Meaning |
|---|---|
| Integrated Operations Centre (IOC) | The interface for monitoring and managing Red Sea Global destinations |
| Digital Twin | The live 3D representation of the destination, rendered on Mapbox GL JS |
| Guest Experience Manager | The Guest Experience Management persona |
| Operations Manager | The Operations persona |
| Environment Manager | The Environment persona |
| Marine Operations Manager | The Marine Operations persona |
| Map LOD | Map level of detail, the destination, district, and site tiers (map LOD 1/2/3) |
| CCTV | Closed-circuit television, the live camera grid |
| Simulation | Modelling a scenario on the twin to assess possible outcomes and responses |

<Callout type="note">
This glossary covers the terms currently documented. Confirm the formal persona expansions against the RSG IOC Technical statement of work.
</Callout>
